# BotCount

Сервис для определения ботов на основе анализа частоты событий пользователей в заданном временном окне.

## Установка и запуск

```bash
cargo install --git https://github.com/VanyaGlazunov/BotCount.git --branch dev

Botcount --timestamp-threshold <SECONDS> --event-count-limit <LIMIT> --port <PORT>
```

**Параметры:**
- `--timestamp-threshold` или `-t`: Временное окно в секундах для анализа событий
- `--event-count-limit` или `-e`: Количество событий, после которого пользователь считается ботом
- `--port` или `-p`: Порт для запуска сервера (по умолчанию: 8080)

### Удалить
```bash
cargo uninstall BotCount
```

## API

### POST /event
Добавляет новое событие пользователя.

```bash
curl -X POST http://127.0.0.1:8080/event \
  -H "Content-Type: application/json" \
  -d '{"user_id": 1, "timestamp": 100}'
```

**Ответ:** HTTP 200 OK

### GET /bots?timestamp=<TIMESTAMP>
Возвращает количество ботов на указанный момент времени.

```bash
curl http://127.0.0.1:8080/bots?timestamp=199
```

**Ответ:**
```json
{
  "bot_count": 2
}
```

## Асимптотическая сложность

### Операции
- **`add_event`**: O(1) амортизированная
  - Добавление события в конец очереди: O(1)
  - Обновление счётчика пользователя в HashMap: O(1) амортизированная

- **`count_bots`**: В худшем случае O(n) где n кол-во запросов. O(1) амортизированная.  
  - Пробегает все устаревшие события в очереди единожды

### Память
- **O(n + m)**, где:
  - n — количество событий в текущем временном окне
  - m — количество уникальных пользователей
